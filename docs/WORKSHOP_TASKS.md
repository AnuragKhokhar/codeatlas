# Workshop Tasks — TDD with Specialized Agents

1. **Understand the harness:** Read AGENTS.md, TDD_WORKFLOW.md and AGENT_HANDOFF_CONTRACT.md. Run repository checks.
2. **Plan a vertical slice:** Ask the Orchestrator and Planner to plan import of a synthetic solved-problems CSV. Review the plan and API contract.
3. **Write tests first:** Run FE and BE Test Engineers from the same approved criteria and contract. Inspect tests before implementation.
4. **Observe RED:** Run tests against missing behavior. Confirm failures are meaningful, not test setup errors.
5. **Implement GREEN:** Authorize FE and BE Implementers. They write production code only. Reject attempts to weaken tests.
6. **Refactor and document:** Preserve behavior; ask Documentation Engineer to update docs from verified implementation.
7. **Review and repair:** Run Reviewer, bounded self-healing, all checks and inspect final verification.
8. **Demonstrate:** Start the application using the chosen stack's documented command and open its forwarded Codespaces port.
