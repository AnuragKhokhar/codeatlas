# Definition of Done

- Acceptance criteria mapped to implementation and tests.
- Architecture boundaries and source-data policy respected.
- Input validation and useful failure states implemented.
- Tests added for happy paths, malformed data, duplicates and failures.
- Existing tests retained; no weakened assertions.
- Formatting/lint/tests/policy checks pass.
- README and relevant docs updated.
- PR includes scope, screenshots where useful, test evidence and known limitations.
